MY LIFE DIARY - PWA 설치 파일

구성
- index.html: 다이어리 본체 (70일 기도, 7일 단위 성취도, 광명진언 0/1000 계수기 포함)
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 오프라인 캐시 및 앱 업데이트 처리
- icon-*.png: 앱 아이콘

중요
PWA는 보안상 HTTPS 주소에서 열어야 설치 메뉴와 오프라인 기능이 정상 작동합니다.
이 ZIP은 설치 가능한 웹앱 패키지이며, 아직 인터넷 주소에 게시된 상태는 아닙니다.

게시 및 갤럭시 설치
1. ZIP 압축을 풀어 파일 6개를 확인합니다.
2. HTTPS 정적 웹 호스팅(예: GitHub Pages, Cloudflare Pages)에 폴더 내용을 게시합니다.
3. 갤럭시 Chrome에서 게시된 HTTPS 주소를 엽니다.
4. Chrome 메뉴(⋮) > 앱 설치 또는 홈 화면에 추가를 누릅니다.
5. 홈 화면에 생성된 MY LIFE DIARY 아이콘으로 실행합니다.

기록 데이터
기록은 해당 브라우저의 로컬 저장공간에 보관됩니다. 브라우저 데이터 삭제, 앱 제거, 기기 변경 전 설정 메뉴에서 JSON 백업을 내보내세요. 다른 브라우저나 기기와 자동 동기화되지는 않습니다.
