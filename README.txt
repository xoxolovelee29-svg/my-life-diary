MY LIFE DIARY - PWA 업데이트 패키지

[업데이트 방법]
1. ZIP 압축을 풀면 index.html, sw.js, manifest.webmanifest, 아이콘 파일들이 나옵니다.
2. GitHub 저장소의 최상위(root) 화면에서 Add file > Upload files를 선택합니다.
3. 압축을 푼 파일을 모두 선택해 업로드합니다. 기존 index.html과 sw.js는 같은 이름으로 교체됩니다.
4. Commit changes를 눌러 저장합니다.
5. GitHub Pages 배포가 끝나면 앱 주소를 브라우저에서 다시 엽니다.
6. 기존 PWA의 서비스워커 캐시 이름을 v2로 변경해 새 파일을 받도록 했습니다.

[포함 기능]
- 홈 메뉴 4개: 기도, 다이어트, 부업, 공부
- 공부 시간: 시간/분 입력 및 날짜별 합계
- 홈 날짜 옆 작은 달력 버튼, 근무 유형별 파스텔 색상과 일일 체크리스트 달성률
- 날짜 선택 시 공부 시간 및 일일 부업 수익 요약
- 근무 유형별 수정된 일정
- 기도 시작일과 49/70/100일 또는 사용자 지정 기간 설정
- 체크리스트 항목 추가/수정/삭제, 공부 체크 항목 제외
- 체중 목표 55kg, 식사별 음식/칼로리, 총 칼로리, 수분 리터, 운동 기타 메모
- 채널 이름 직접 설정, 채널별 업로드/조회수/수익 및 합계
- 백업/복원

[중요]
- 기존 localStorage 저장 키(mylifediary_v1)를 유지했습니다.
- 기존 공부 시간 기록(분 단위)은 그대로 보존되며 새 화면에서 시간/분으로 표시됩니다.
- 기존 부업 수익은 과거 날짜 요약에 포함되도록 유지했습니다.
- 업데이트 전 앱 설정에서 백업을 내려받는 것을 권장합니다.


[일정 관리 업데이트]
- 일정 관리 메뉴 추가: 월간 달력, 날짜별 일정, 카테고리, 시간, 메모, 반복(매주/매월), 완료/수정/삭제
- 오늘 일정이 있을 때만 홈 화면에 오늘의 일정 카드가 자동 표시됩니다.
- 일정은 기존 앱 데이터와 별도 events 항목으로 저장되며 기존 기록은 유지됩니다.
