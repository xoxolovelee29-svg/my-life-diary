MY LIFE DIARY - 이모지 및 레드 아이콘 업데이트 패키지

[업데이트 방법]
1. ZIP 압축을 풉니다.
2. GitHub 저장소 최상위(root)에 포함된 파일 전체를 업로드해 기존 파일을 교체합니다.
3. Commit changes 후 GitHub Pages 배포가 완료될 때까지 기다립니다.
4. 앱을 완전히 종료한 뒤 다시 실행합니다. 필요하면 브라우저에서 사이트 데이터를 새로고침합니다.
